# KIBERone & RENDERIA Business Assistant

Внутренний рабочий ИИ-кабинет для управляющей двух детских образовательных школ: **KIBERone** и **Renderia**.

## Возможности

- **Разделение школ**: Строгая изоляция Базы знаний и контекста между KIBERone и Renderia.
- **ИИ-специалисты**: Профильные ассистенты (Маркетолог, Менеджер, Методист, Аналитик) с защитой от домыслов.
- **Интерактивный цифровой спутник «Пиксель»**: Живой собеседник, координатор задач, голосовой интерфейс и визуальный анимированный персонаж.
- **Поддержка голоса**: Gemini Live API (двусторонний голосовой диалог в реальном времени), озвучивание ответов через Gemini TTS и локальный Web Speech API.
- **Локальное хранение**: Все документы, базы знаний, диалоги и история сохраняются локально в IndexedDB без внешних серверов баз данных.
- **Поддержка настольной версии**: Полноценное Windows-приложение (.exe) с установщиком на базе Electron.

## Сборка настольного Windows-приложения

Подробная инструкция по сборке установщика `.exe` доступна в файле [README_WINDOWS_BUILD.md](./README_WINDOWS_BUILD.md).

```bash
# Сборка инсталлятора для Windows (.exe в папке release/):
npm run electron:build

# Сборка распакованного Windows-приложения (в release/win-unpacked/):
npm run electron:pack
```

## Запуск в режиме веб-разработки

```bash
# Запуск веб-сервера разработки:
npm run dev
```
