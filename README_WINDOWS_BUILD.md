# KIBERone & RENDERIA Business Assistant — Сборка Windows-приложения (.exe)

Это руководство описывает процесс сборки и развёртывания **KIBERone & RENDERIA Business Assistant** как полноценного настольного приложения для Windows с установщиком (.exe).

---

## 🎯 Что было реализовано

1. **Electron & electron-builder**: аккуратно интегрированы в проект без нарушения существующей архитектуры React 19 + TypeScript + Express + Vite.
2. **Автономный запуск**: приложение открывается как отдельное окно Windows. Пользователю не требуется вручную открывать командную строку, запускать Node.js или открывать браузер.
3. **Встроенный Express & WebSocket сервер**:
   - Express API и WebSocket-сервер для Gemini Live API (`/api/live`) запускаются автоматически в фоновом режиме на локальном адресе `127.0.0.1:3000` (с автоматическим выбором свободного порта, если 3000 занят).
   - Все относительные запросы (`/api/chat`, `/api/voice/*`, `/api/ai/*`) и живое голосовое общение работают «из коробки».
4. **Безопасное хранение API-ключей Gemini**:
   - Ключи **не встраиваются** в установщик и не передаются в исходном коде.
   - На компьютере пользователя ключи шифруются через **Windows DPAPI** (`electron.safeStorage`) и хранятся в защищённом хранилище `%APPDATA%\kiberone-renderia-assistant\ai-connections-vault.json`.
   - Ключ передаётся напрямую в память сервера и **не попадает в renderer** (в интерфейсе отображается только безопасная маска `••••••••`).
5. **Сохранение данных и IndexedDB**:
   - База знаний, загруженные документы, история диалогов специалистов, память и задачи Пикселя сохраняются в постоянном профиле Chromium IndexedDB (`%APPDATA%\kiberone-renderia-assistant\IndexedDB`).
   - Данные сохраняются при перезагрузках, обновлениях приложения и переносе резервных копий.
6. **Голосовая система и Пиксель**:
   - Сохранены все функции интерактивного спутника Пикселя, эмоции, анимации, локальный и облачный TTS, а также Gemini Live API.
   - В Electron настроен автоматический допуск к микрофону для живого разговора.
7. **Фирменные иконки**:
   - Сгенерированы 256×256 иконки `build/icon.ico` и `build/icon.png`.
   - Установщик и ярлык на рабочем столе используют официальную иконку.

---

## 🚀 Команды для сборки

### 1. Полная сборка установщика Windows (.exe)
```bash
npm run electron:build
```
Эта команда выполняет:
1. `npm run build` — компиляцию фронтенда Vite в папку `dist/`.
2. `npm run build:electron` — бандлинг `electron/main.ts` и `electron/preload.ts` в `dist-electron/`.
3. `electron-builder --win` — упаковку приложения в установщик NSIS.

**Результат сборки находится в папке `release/`:**
- `release/KIBERone & RENDERIA Business Assistant-Setup-1.0.0.exe` — готовый инсталлятор для Windows.

---

### 2. Сборка распакованной переносной версии (Portable / Unpacked)
```bash
npm run electron:pack
```
Создаёт готовую к запуску папку с исполняемым файлом без необходимости установки:
- `release/win-unpacked/KIBERone & RENDERIA Business Assistant.exe`

---

### 3. Запуск в режиме разработки Electron
```bash
npm run electron:dev
```
Запускает локальную сборку Electron для отладки окна, IPC и взаимодействия с сервером.

---

### 4. Перегенерация иконок
```bash
npm run build:icons
```
Создаёт и обновляет `build/icon.ico`, `build/icon.png`, `public/icon.ico`, `public/icon.png`.

---

## 🎨 Где лежит иконка и как её заменить

Файлы иконок расположены по путям:
- **`build/icon.ico`** (основная иконка для Windows `.exe` и установщика NSIS, формат ICO, 256×256).
- **`build/icon.png`** (исходная растровая иконка PNG, 256×256).
- **`public/icon.ico`** (иконка для веб-версии и окна).

### Инструкция по замене:
1. Подготовьте изображение вашего логотипа квадратного формата (рекомендуется 512×512 или 256×256 пикселей).
2. Сконвертируйте его в формат `.ico` (включающий слои 256×256, 128×128, 64×64, 48×48, 32×32, 16×16).
3. Замените файл `build/icon.ico`.
4. Запустите повторную сборку `npm run electron:build`.

## 🔐 Настройка API-ключа Gemini у пользователя

После установки приложения на компьютер:
1. Запустите приложение с рабочего стола или из меню «Пуск».
2. В боковом меню перейдите в раздел **«Подключения ИИ»**.
3. В карточке **Google Gemini** нажмите **«Настроить»** (или «Редактировать»).
4. Вставьте ваш бесплатный ключ Google Gemini API (полученный в Google AI Studio) и нажмите **«Сохранить»**.
5. Ключ мгновенно зашифруется с помощью криптографической службы Windows DPAPI и сохранится только на компьютере пользователя.

## 📂 Папки данных на компьютере пользователя

При работе установленной программы все пользовательские данные сохраняются в стандартной папке Windows:
```
%APPDATA%\kiberone-renderia-assistant\
```
- `IndexedDB/` — локальная база данных (сообщения, документы, история, память Пикселя).
- `ai-connections-vault.json` — зашифрованные профили API-ключей.

## ⚠️ Особенности и ограничения кросс-компиляции

- **Сборка на Windows**: команда `npm run electron:build` выполняется нативно, быстро и собирает как `.exe` установщик (NSIS), так и распакованную версию.
- **Сборка на Linux/CI без Wine**: для создания однофайлового установщика NSIS на машинах Linux требуется установленный пакет `wine`. Если Wine не установлен в Linux-окружении, используйте команду `npm run electron:pack`, которая создаёт полноценное Windows-приложение в папке `release/win-unpacked/` без использования Wine.
